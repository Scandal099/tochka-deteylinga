# Правила дизайна и данных

- При работе с UI используй компоненты `shadcn` и акценты `magic-ui` (через MCP), избегай дешёвого шаблонного вида («нейрослопа»).
- Соблюдай высокий контраст, крупную читаемую типографику и достаточное количество свободного пространства.
- Проверяй адаптивность: мобильная версия (ширина 375px) так же важна, как десктоп, так как владельцы бизнеса открывают демо-ссылки с телефона.
- Если сайт является демо-концептом для холодного показа — в футере обязательна аккуратная плашка: «Демо-концепт, удалим по первой просьбе».
